# ひらがな麻雀

ひらがなを牌にした一人プレイ用の麻雀シミュレータ。シャンテン計算は Rust + WebAssembly。
スマホ対応の静的サイトで、サーバは不要。

## ルール

- 牌 = ひらがな **81種**（清音46 / 濁音20 / 半濁音5 / 小書き9 / 長音「ー」1）× 各4枚
- **面子** = 辞書にある **3文字の単語**（牌の並べ替え自由・アナグラム可）
- **雀頭** = 辞書にある **2文字の単語**
- **あがり** = 4面子 + 1雀頭（計14枚）
- **暗槓** = 4文字以上（設定で 4/5/6 文字に変更可）の単語を手牌から宣言。
  1面子として数え、（文字数 − 3）枚を嶺上ツモする
- **加槓（小明槓）** = 宣言済みの単語に手牌の1枚を足して1文字長い単語にする。
  繰り返し可能（4文字 → 5文字 → 6文字 → …）。1枚嶺上ツモする

## 機能

- **シャンテン数の常時表示**（テンパイ / あがり演出つき）
- **有効牌ハイライトつきキーボード**: シミュレータなのでツモは下のキーボードから
  自由に選択（ランダムツモも可）。光っている牌 = シャンテン数が下がる有効牌、
  右下の数字 = 山の残り枚数
- **打牌ヒント**: シャンテン数を保つ打牌に緑の点
- **単語リスト**: いま手牌から作れる単語と、あと1枚で作れる3文字語
  （完成牌の残り枚数が多い順）
- **手牌編集**: ポップアップから任意の13枚を入力して局面をセット可能
- スマホ最適化 UI（safe-area / dvh 対応）

## ディレクトリ構成

```
hiragana-mahjong/
├── crate/            # Rust コアエンジン (wasm-bindgen)
│   ├── src/lib.rs    # シャンテン計算・有効牌・単語/カン候補・和了判定
│   └── examples/bench.rs
├── tools/build_dict.py  # 辞書生成 (mecab-ipadic → web/dict.txt)
└── web/              # 静的サイト本体
    ├── index.html / style.css / main.js
    ├── dict.txt      # 生成済み辞書 (約4.7万語)
    └── pkg/          # wasm-pack 出力 (コミット済み)
```

## ビルド・実行

そのまま静的配信すれば動く（`web/pkg` と `web/dict.txt` はコミット済み）:

```sh
cd web && python3 -m http.server 8000
# → http://localhost:8000/
```

Rust を変更したら:

```sh
cd crate
cargo test
wasm-pack build --target web --release --out-dir ../web/pkg
```

辞書を作り直すには:

```sh
python3 tools/build_dict.py web/dict.txt
```

## シャンテン計算について

- 面子候補 = 手牌の3枚部分集合のうち辞書語のアナグラムになるもの。
  DFS で面子を選び、残りから部分面子（ターツ = 3文字語の2枚部分で、完成牌が
  まだ4枚使われていないもの）と雀頭（2文字語）の最大数を分枝限定法で求める。
- `シャンテン = 2 × (必要面子数 − 面子) − ターツ − 雀頭`
- 有効牌 = 手牌のどれかとターツ・雀頭関係を持つ牌のうち、加えるとシャンテン数が
  下がるもの（全種を試す前に候補を絞る）。
- 簡略化: ターツの完成牌の枚数チェックは自分の手牌でのみ行い、捨て牌・宣言済み
  面子は考慮しない（実用上ほぼ影響なし）。
