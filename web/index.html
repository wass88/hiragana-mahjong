単語リスト

いま作れる単語

あと1枚で作れる3文字語 (残り枚数が多い順)

手牌編集

13枚を選んでください。確定すると局がリセットされます(宣言済みのカン・捨て牌はクリア)。

🎉 あがり！

ルール

  • 牌はひらがな75種(清音45・濁音20・半濁音5・拗音「っゃゅょ」4・長音「ー」1。「を」と小書き「ぁぃぅぇぉ」は無し)。枚数は清音2枚、それ以外1枚。
  • 面子 = 辞書にある3文字の単語(文字の並べ替え自由)。
  • 雀頭 = 辞書にある2文字の単語。
  • あがり = 4面子 + 1雀頭(計14枚)。
  • 暗槓 = 4文字以上の単語を手牌から宣言。1面子として数え、(文字数−3)枚を嶺上ツモ(自動でランダム補充)。
  • 加槓(小明槓) = 宣言済みの単語に手牌の1枚を足して1文字長い単語にする。繰り返し可。1枚嶺上ツモ(自動でランダム補充)。
  • ツモは下のキーボードから自由に選べるシミュレータ。光っている牌が有効牌(シャンテン数が下がる牌)、数字は山の残り枚数。
  • 手牌の牌はタップで選択(再タップで解除)。1枚選んで「捨てる」で打牌(緑の点が付いた牌はシャンテン数を保つ打牌)。
  • 3枚選んで単語になっていれば自動でトリオにまとまる(見た目の整理用。実際の単語の並び順で表示。トリオ内の牌をタップすると崩して選び直せる。単語でなければ選択が弾かれる)。
  • カン = 「カン」を押す(選択モードに入る)→牌を選ぶ(暗槓は4枚以上、加槓は宣言済み面子をタップして対象を選んでから追加牌を1枚)→もう一度「カン」で判定(単語ならカン、そうでなければ選択解除)。
  • あがり形になったら「ツモ」ボタンで宣言(押すまでは打牌やカンも可能)。

設定

辞書: mecab-ipadic の一般名詞・サ変名詞・副詞可能名詞のうち、 hingston/japanese の頻度語彙リスト(Leeds Corpus由来)に収録されている語のみを採用(約2万語)。
